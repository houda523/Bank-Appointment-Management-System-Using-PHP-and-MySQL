# Bank Appointment Management — PHP/MySQL Demo

A reconstructed academic starter for scheduling appointments. It is not a copy of any former internship or bank system.

## Features
- Create an appointment with a synthetic name, email, date and purpose.
- List appointments in a local MySQL database.
- Basic input validation and prepared SQL statements.

## Setup
1. Install PHP 8+ and MySQL/MariaDB (XAMPP is suitable for local practice).
2. Create a database using `schema.sql`.
3. Configure local database credentials in `config.php` (never commit real credentials).
4. Place the folder in your local web root and open `index.php`.

## Security limitations
This is a learning demo, not production-ready banking software. It does not implement login, CSRF protection, role permissions, or production deployment hardening. Use fictitious data only.
